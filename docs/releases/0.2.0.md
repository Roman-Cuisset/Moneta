# Moneta Alpha 0.2.0

## Français

**Vous utilisez l’Alpha 0.1.0 ?** Téléchargez l’installateur 0.2.0 ci-dessous, fermez Moneta puis lancez l’installateur. Ce passage est exceptionnellement manuel. Vos dossiers restent à leur emplacement. Dès la 0.2.0, Moneta peut détecter les prochaines préversions Alpha publiées sur GitHub et vérifier leur catalogue signé avant de proposer une installation.

- L’interface est disponible en français et en anglais américain. Le logo C est utilisé dans l’application, l’icône Windows et l’installateur.
- Les fichiers `.moneta` peuvent être ouverts avec Moneta depuis l’Explorateur. Windows conserve le choix de l’application par défaut. Une demande d’ouverture rejoint la fenêtre Moneta déjà en cours, avec confirmation pour les saisies et modifications en attente.
- La saisie rapide sous le registre ajoute une dépense ou une recette au brouillon. Entrée valide une saisie et Ctrl+S enregistre les brouillons. La fenêtre détaillée et la commande de virement restent accessibles. Les suggestions reprennent les valeurs du dossier.
- Les champs de montant acceptent la virgule et le point décimaux dans les deux langues. Une saisie telle que `1,234` peut signifier 1 234 ou 1,234. Utilisez `1 234` pour les milliers ou `1,2340` pour une valeur à trois décimales si la devise l’autorise.
- La barre d’outils espace ses boutons. Le menu **Affichage → Densité du registre** permet de choisir **Standard** ou **Compact**. Le volet de détails continue de présenter les informations de l’écriture sélectionnée.
- Le registre distingue la date de valorisation, la publication utilisée et le cache. Une recherche historique dans la fenêtre des cours garde son propre contexte. Les valorisations historiques et les taux effectifs enregistrés restent associés à leurs données d’origine.
- La fenêtre principale s’ouvre dans la zone de travail du moniteur courant : une position hors écran est corrigée et une taille supérieure à l’écran est réduite. La géométrie et l’état agrandi sont restaurés à la réouverture. Voir `docs/WINDOW_PLACEMENT.md`.
- La fermeture de la fenêtre principale est différée jusqu’au retour de l’événement de fermeture WPF. La fenêtre **À propos** donne accès à la licence MIT et aux notices des composants.

Cette Alpha cible Windows 11 x64. L’import BankPerfect V5 contrôle les anciens fichiers et refuse un dossier lorsqu’il ne peut pas établir les liens de virement. Les estimations en devises dépendent des publications officielles ou d’un cache applicable. L’installateur est dépourvu de signature Authenticode. Windows peut afficher un avertissement SmartScreen. Le catalogue de mise à jour possède une signature distincte.

## English

**Using Alpha 0.1.0?** Download the 0.2.0 installer below, close Moneta, then run the installer. This upgrade is a one-time manual step. Your documents stay in their current locations. Starting with 0.2.0, Moneta can discover future Alpha prereleases on GitHub and verify their signed catalogs before offering installation.

- The app is available in French and US English. The app, Windows icon and installer use the updated Moneta logo.
- Open `.moneta` files with Moneta from File Explorer. Windows retains your default-app choice. If Moneta is already running, its window receives the request and asks what to do with pending entries or changes.
- Enter an expense or income below the register. Enter stages the entry and Ctrl+S saves staged changes. The detailed transaction dialog and transfer command remain available. Suggestions come from your document.
- Amount fields accept a decimal comma or point in either language. `1,234` can be a grouped integer or a decimal. Use `1 234` for thousands or `1.2340` for a three-decimal value when the currency supports it.
- The toolbar has more space between buttons. Choose **View → Register density → Standard / Compact**. The details pane still shows the selected transaction’s information.
- The register identifies the valuation date, the publication used and cached rates. A past date selected in the rates window has its own context. Historical valuations and stored effective transfer rates retain their original data.
- The main window opens inside the current monitor work area: an off-screen position is corrected and an oversized window is reduced. Geometry and maximized state are restored on reopening. See `docs/WINDOW_PLACEMENT.md`.
- The main window defers its final close until the WPF closing event has returned. The **About** window gives access to the MIT license and third-party notices.

This Alpha targets Windows 11 x64. The BankPerfect V5 importer validates legacy files and rejects a document if it cannot establish transfer links. Currency estimates depend on official publications or an applicable cache. The installer has no Authenticode signature. Windows may display a SmartScreen warning. The update catalog has a separate signature.
