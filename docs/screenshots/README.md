## Replacing or adding screenshots

- Use only a demonstration or otherwise entirely fictional document.
- Do not include real names, account numbers, balances, file paths, e-mail addresses, or notifications.
- Capture the application window itself, without the desktop or personal taskbar content.
- Keep the interface in its real state; do not retouch data, controls, or labels.
- Prefer PNG and a readable width around 1200–1600 pixels for the main window.
- Keep the set small. Two or three images are enough for the landing page.

Useful additions, once suitable data exists:

- Budgets or a report with visible results, rather than an empty month.
- A multi-currency transfer or the conversion view.
- The BankPerfect import preview.
- The update window with signed release notes.
